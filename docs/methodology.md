# Methodology: Mathematical Morphological Reconstruction (MMR) for Brain MRI Analysis

## 1. Theoretical Foundation

Mathematical morphology is a geometric framework for spatial shape analysis founded on set theory, complete lattices, and topology (Matheron 1975, Serra 1982). Unlike linear spatial filters (such as Gaussian or box filters) that operate by convolving spatial coordinates and blurring object boundaries, morphological operators operate on the local ordering of gray levels and preserve structural boundaries.

### 1.1 Elementary Morphological Operations

Let $f(x, y)$ be a grayscale image and $B$ a 2D structuring element (footprint). The standard morphological dilation ($\oplus$) and erosion ($\ominus$) are defined by:

$$(f \oplus B)(x, y) = \sup_{(s, t) \in B} \{ f(x - s, y - t) \}$$

$$(f \ominus B)(x, y) = \inf_{(s, t) \in B} \{ f(x + s, y + t) \}$$

Standard morphological opening $\gamma_B(f) = (f \ominus B) \oplus B$ eliminates bright peaks smaller than $B$. However, standard opening rounds sharp corners, degrades object geometry, and causes severe boundary displacement.

---

## 2. Mathematical Morphological Reconstruction (MMR)

Morphological reconstruction is based on **geodesic transformations** under a reference mask constraint (Vincent 1993, Soille 2003).

### 2.1 Marker and Mask Invariants

Reconstruction requires two input images defined on identical spatial domains:
1. **Mask Image $f$:** The reference intensity image containing structural boundaries.
2. **Marker Image $g$:** The seed image containing starting points for geodesic propagation.

Mathematical constraints:
- **For Dilation-based Reconstruction:** $g(x, y) \le f(x, y) \quad \forall (x, y)$
- **For Erosion-based Reconstruction:** $g(x, y) \ge f(x, y) \quad \forall (x, y)$

### 2.2 Geodesic Dilation

The elementary geodesic dilation of size 1 of marker $g$ with respect to mask $f$ is:

$$\delta^{(1)}_f(g) = (g \oplus B) \wedge f$$

where $\wedge$ denotes the pointwise minimum:

$$(g \wedge f)(x, y) = \min(g(x, y), f(x, y))$$

The geodesic dilation of size $k$ is obtained by $k$ successive recursive iterations:

$$\delta^{(k)}_f(g) = \delta^{(1)}_f\left( \delta^{(k-1)}_f(g) \right)$$

### 2.3 Morphological Reconstruction by Dilation

The morphological reconstruction by dilation $R^\delta_f(g)$ is the stationary limit of repeated geodesic dilations:

$$R^\delta_f(g) = \lim_{k \to \infty} \delta^{(k)}_f(g)$$

Because the domain is finite and bounded by $f$, convergence is guaranteed in a finite number of iterations:

$$\exists K \in \mathbb{N} \quad \text{such that} \quad \delta^{(K)}_f(g) = \delta^{(K-1)}_f(g)$$

## 3. Reconstruction Operators for Lesion Identification

### 3.1 Opening by Reconstruction (OBR)

In Opening by Reconstruction:
1. The preprocessed MRI is taken as the mask: $f = I_{\text{pre}}$.
2. The marker is generated by morphological erosion of the mask: $g = f \ominus B$.
3. Geodesic reconstruction by dilation is performed: $R^\delta_f(f \ominus B)$.

**Key Advantage:** Bright objects larger than the structuring element $B$ are fully reconstructed to their exact original shape without edge smoothing or corner rounding. Objects smaller than $B$ are completely suppressed.

### 3.2 White Top-Hat by Reconstruction (Residual Extraction)

The candidate abnormal focal regions are extracted by computing the residual difference between the original preprocessed mask and its opening by reconstruction:

$$\text{WTH}(f) = f - R^\delta_f(f \ominus B)$$

Properties of $\text{WTH}(f)$:
- Suppresses slowly varying background brain parenchyma.
- Selectively enhances hyperintense focal peaks (contrast-enhancing lesions, focal nodules) whose spatial radius is $\le$ the structuring element radius.
- Produces sharp zero-background contrast maps ideal for thresholding.

### 3.3 H-Dome Reconstruction

For regional peak isolation regardless of size:
1. Marker: $g = \max(0, f - h)$ where $h > 0$ is a height threshold parameter.
2. Reconstruction: $R^\delta_f(f - h)$.
3. H-Dome Residual: $\text{HD}_h(f) = f - R^\delta_f(f - h)$.

Isolates all intensity peaks whose local prominence exceeds $h$.

## 4. Candidate Region Segmentation & Refinement

After obtaining the normalized residual map $I_{\text{res}} \in [0, 1]$:

1. **Automated Thresholding:**
   - **Otsu's Criterion:** Minimizes intra-class variance $\sigma_w^2(t) = \omega_0(t)\sigma_0^2(t) + \omega_1(t)\sigma_1^2(t)$.
   - **Triangle / Percentile / Manual Cutoffs:** For high-contrast or sparse lesion profiles.

2. **Morphological Cleanup:**
   - **Opening ($\gamma$):** Eliminates isolated single-pixel spurs.
   - **Closing ($\phi$):** Bridges micro-cavities within candidate lesion tissue.
   - **Hole-filling:** Fills interior hypointense lacunae.

3. **Connected Component Filtering:**
   - Evaluates pixel area $A_i$ for each component $i$.
   - Rejects components where $A_i < \text{min\_area}$ (suppressing acquisition noise).
   - Labels remaining components strictly as **candidate abnormal regions**.

---

## 5. Quantitative Feature Extraction

For each candidate region, the following geometric and radiometric measurements are calculated:

| Feature | Formula / Definition | Interpretation |
|---|---|---|
| **Area** | $A = \sum_{(x, y) \in R} 1$ | Total pixel count |
| **Centroid** | $(\bar{x}, \bar{y}) = \left(\frac{1}{A}\sum x, \frac{1}{A}\sum y\right)$ | Spatial mass center |
| **Bounding Box** | $[y_{\min}, x_{\min}, y_{\max}, x_{\max}]$ | Orthogonal spatial extent |
| **Perimeter** | $P = \oint_{\partial R} ds$ | Exact contour length |
| **Aspect Ratio** | $\text{AR} = \frac{\text{Width}}{\text{Height}}$ | Elongation along cardinal axes |
| **Circularity** | $C = \frac{4\pi A}{P^2} \quad (C \in [0, 1])$ | Isoperimetric quotient (1.0 = circle) |
| **Solidity** | $S = \frac{A}{A_{\text{convex hull}}}$ | Cavity and boundary irregularity |
| **Extent** | $E = \frac{A}{\text{BBox Area}}$ | Rectangular occupancy ratio |
| **Mean Intensity** | $\mu_I = \frac{1}{A}\sum_{(x,y) \in R} I(x, y)$ | Radiometric signal brightness |

---

## 6. Quantitative Ground-Truth Evaluation Metrics

When an expert reference mask $G$ is provided, candidate mask $P$ is evaluated using:

1. **Dice Similarity Coefficient (DSC / F1-Score):**
   $$\text{DSC} = \frac{2 |P \cap G|}{|P| + |G|} = \frac{2 \cdot \text{TP}}{2\cdot\text{TP} + \text{FP} + \text{FN}}$$

2. **Intersection over Union (IoU / Jaccard Index):**
   $$\text{IoU} = \frac{|P \cap G|}{|P \cup G|} = \frac{\text{TP}}{\text{TP} + \text{FP} + \text{FN}}$$

3. **Sensitivity (Recall / True Positive Rate):**
   $$\text{Sensitivity} = \frac{\text{TP}}{\text{TP} + \text{FN}}$$

4. **Specificity (True Negative Rate):**
   $$\text{Specificity} = \frac{\text{TN}}{\text{TN} + \text{FP}}$$

5. **Precision (Positive Predictive Value):**
   $$\text{Precision} = \frac{\text{TP}}{\text{TP} + \text{FP}}$$
